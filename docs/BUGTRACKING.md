# Bugtracking
Ferramenta: **GitHub Issues** do repositório (aba *Issues* > *New issue*), com os rótulos `bug`, `critico/alto/medio/baixo`.
Para cada falha encontrada nos testes: abra uma issue com o modelo abaixo, corrija no código e feche a issue citando o commit
(`git commit -m "Corrige validação de telefone (fixes #1)"` fecha a issue #1 automaticamente no GitHub).

## Modelo de issue
**Caso de teste:** CT-__  **Severidade:** crítica / alta / média / baixa
**Passos para reproduzir:** 1. ... 2. ...
**Resultado esperado:** ...  **Resultado obtido:** ...  **Print:** (anexar)
**Correção:** commit __ (preencher ao fechar)
